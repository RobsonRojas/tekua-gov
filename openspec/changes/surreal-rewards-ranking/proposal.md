# Proposal: Surreal Rewards Ranking

## 1. The Problem
Atualmente, não há um sistema de gamificação robusto que incentive os membros a executarem tarefas em troca de recompensas tangíveis (prêmios) usando seus "surreais" acumulados, nem uma forma de acompanhar o desempenho competitivo entre os membros.

## 2. The Solution
Criar um sistema de prêmios onde o admin da plataforma pode cadastrar recompensas. Os membros poderão resgatar esses prêmios automaticamente assim que atingirem a quantidade necessária de surreais.
Além disso, será criada uma página pública/compartilhável de ranking para cada prêmio, mostrando o desempenho dos membros. Esta página terá um botão de "Call to Action" direcionando o usuário para o "work wall" onde poderão executar mais tarefas para ganhar surreais.

## 3. Key Features
- **Gestão de Prêmios (Admin):** Interface para criar, editar e excluir prêmios (nome, descrição, custo em surreais, imagem, data limite opcional).
- **Notificações e Engajamento:** Sistema de notificações, lembretes e emails periódicos para incentivar os membros a participarem das campanhas.
- **Resgate Automático:** Lógica que garante automaticamente o prêmio ao usuário que participa e atinge a pontuação dentro do prazo (se aplicável).
- **Página de Ranking:** Uma página dedicada e compartilhável para cada prêmio mostrando quem está na frente.
- **Integração com Work Wall:** Botões na página de ranking incentivando a execução de tarefas.
