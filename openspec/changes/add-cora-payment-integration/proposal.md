# Proposal: Add Cora Payment Integration

## What
Implement a Supabase edge function in the backend to handle payment integrations with Cora Pro. The integration must support generating and processing payments via:
- Boleto
- PIX
- Cartão (Credit Card)

## Why
To allow users to complete transactions securely and seamlessly within the Tekua Gov system using the Cora Pro payment gateway, enabling a variety of payment methods and automated webhook processing.
