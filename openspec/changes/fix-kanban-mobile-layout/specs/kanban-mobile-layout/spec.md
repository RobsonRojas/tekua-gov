# Spec: Kanban Mobile Layout Fixes

## Requirements

1. **Kanban Columns Scroll:**
   - Em dispositivos móveis e telas menores, as colunas do Kanban devem permitir scroll horizontal.
   - O usuário deve conseguir fazer swipe para a esquerda/direita para navegar entre todas as colunas.
   - As colunas não devem encolher a ponto de ficarem ilegíveis, mantendo uma largura mínima razoável.

2. **Filters and Buttons:**
   - Os filtros (Projeto, Executor) e botões de ação acima do Kanban não devem sofrer cortes nas bordas da tela.
   - O layout deve adaptar-se para quebrar a linha (`wrap`) ou ser redimensionado adequadamente em telas menores.
